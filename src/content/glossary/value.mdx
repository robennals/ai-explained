A **value** is a vector each token produces in the attention mechanism, representing *the information it shares* when other tokens attend to it.

Once query–key matching has decided which tokens should pay attention to which, the actual information passed along is the value. The query and key decide *who talks to whom*; the value decides *what gets said*. Each token's new representation is the softmax-weighted blend of every other token's value.

Some examples:

- **A noun's value** — "cat" might have value `[1, 0]` (cat = yes, dog = no); when a pronoun attends to it, the pronoun pulls in that representation.
- **A filler token's value** — essentially empty; even if it accidentally gets attention, it contributes nothing.
- **Two of the same noun** — "dog … dog" — produces a *more confident* answer than one dog (sharper), not a doubled one, because the softmax weighting keeps the blend in the same space.
- **Inside ChatGPT** — every token's value is a high-dimensional vector encoding semantic information; attention blends together values from many tokens to build up each layer's output.

Together with the query and the key, the value is one of the three vectors at the heart of the attention mechanism — query asks, key offers, value shares.
