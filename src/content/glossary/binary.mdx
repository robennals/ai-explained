**Binary** is a way of writing numbers using only two digits, 0 and 1. Computers use it because each digit can be stored as a simple on-or-off signal.

It works just like the ordinary numbers you already use, with 2 in place of 10. In ordinary numbers, each digit is worth ten times the one to its right: 1s, 10s, 100s. So 305 means 3 hundreds, 0 tens, and 5 ones. In binary, each digit is worth *twice* the one to its right: 1s, 2s, 4s, 8s, and so on.

To read a binary number, add up the places that hold a 1:

- **11** = 2 + 1 = 3
- **101** = 4 + 1 = 5
- **110** = 4 + 2 = 6
- **1101** = 8 + 4 + 1 = 13

Counting up from zero in binary goes: 0, 1, 10, 11, 100, 101, 110, 111, 1000.

Adding in binary works like long addition, except that a column carries as soon as it reaches 2, rather than 10. So 1 + 1 = 10: write 0 and carry the 1. The adding circuit in the Neural Networks chapter does exactly this, using AND, OR, and XOR gates.

Each binary digit is called a **bit**. Eight bits can hold any number from 0 to 255, and everything a computer stores, including text, colors, and sound, is ultimately stored as bits.
