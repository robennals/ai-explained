A **tool** is something outside the model, such as a search engine or a calculator, that the model can have run for it by writing a request as text.

The model itself can only write text, so it never runs anything. It writes a *tool call* naming the tool and what to give it. The harness spots that, runs the thing, and pastes the result back into the conversation, where the model reads it like any other message.

Some tools a chat model is commonly given:

- **A calculator or a code sandbox** — the model writes the sum as a program rather than working it out one token at a time, which is far more reliable.
- **Web search** — the model has no idea what today's weather is, so it asks.
- **Your email or files** — it can search for "Bramley invoice", read the message it finds, and tell you whether it was paid.
- **Another program entirely** — anything that takes text in and gives text back can be a tool.

A model that picks tools and works in a loop, reading each result before deciding what to do next, is what people mean by an agent.
