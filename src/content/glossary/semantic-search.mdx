term: semantic search
aliases: [meaning search, vector search]
firstAppearance: context

**Semantic search** is finding documents by nearness in meaning rather than by matching exact words.

Every document is turned into an embedding vector; a query gets embedded the same way, and the search returns whichever documents sit nearest to the query in that vector space. That finds the document that says the right thing in different words, something an exact-text match can't do.

Some examples:

- **"Who was making all that noise?"** — a keyword search finds nothing, since those exact words aren't in the source text; semantic search still finds the sentence about a barking dog.
- **An exact ticket number** — keyword search wins here, since the number is an exact string and semantic search has no "meaning" to match it on.
- **RAG** — retrieval-augmented generation relies on semantic search to decide which documents to paste into a model's context window.
