**Fine-tuning** is further training of an already-trained model on a smaller, more specific set of examples.

Pre-training teaches a model language and general knowledge from an enormous amount of text. Fine-tuning then adjusts it for a particular job using far less data, because the model already knows most of what it needs. The first step in turning a raw model into an assistant is supervised fine-tuning: showing it thousands of examples of a question paired with a good answer, so it learns the pattern of being helpful.

Some examples:

- **Supervised fine-tuning** — teaching a text-continuing model to answer questions instead.
- **Task fine-tuning** — adapting a general model to summarise medical notes, using a few thousand examples.
- **Why it works** — the general knowledge does most of the heavy lifting, so a little specific data goes a long way.
