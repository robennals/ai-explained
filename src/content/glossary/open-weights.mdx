---
term: open weights
aliases: [open weight, open-weight, open-weight model, open weight model]
firstAppearance: real-ai

A model has **open weights** when anyone can download its trained parameters and run it themselves.

Open weights are not the same as open source. You get the finished model and usually a technical report describing how it was built, so you can read its architecture, run it on your own computer, and modify it. What you almost never get is the training data or the exact recipe used to make it. Open weights tell you how a model is *shaped*, not how it was *made*.

Some examples:

- **DeepSeek, Qwen, Kimi, GLM, Llama** — all publish their weights and architecture.
- **gpt-oss** — OpenAI's open-weight model, unusual because OpenAI keeps its main models closed.
- **Claude, GPT-5, Gemini** — closed. You can use them, but you cannot download or inspect them.
- **OLMo and Pythia** — rarer still: these publish the training data as well.
