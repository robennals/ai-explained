---
term: multi-head attention
aliases: [multi-headed attention, multihead attention]
firstAppearance: attention
---

**Multi-head attention** is running many attention heads in parallel, each with its own query, key, and value weights, so the model can learn many different relationships at once.

Understanding a sentence requires asking several kinds of question at the same time: what does this pronoun refer to? What's the subject of this verb? Which clause does this word belong to? Each attention head specialises in one of these questions; together, multi-head attention lets the model handle all of them in a single layer.

Some examples:

- **Two heads** — one head specialises in pronoun resolution, the other in subject–verb linking. Both run on the same tokens at the same time, and their outputs are combined into the next layer's input.
- **GPT-3** — 96 heads per layer; every token gets 96 simultaneous "questions" asked about it at every layer.
- **Frontier models** — even more heads, learning a wider variety of patterns.

Multi-head attention is what gives transformers their remarkable ability to handle complex grammar and reasoning — the model isn't picking one kind of attention, it's getting them all in parallel.
