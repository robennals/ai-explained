A **skill** is a document of instructions that a model can fetch when it decides the job needs them.

The model is shown a list of skill names with one line each on when they apply. The model then asks for the full skill instructions only when that skill looks relevant. A skill will often contain instructions for using a tool, and describe personal customizations to how you want the model to do particular tasks.

Examples of skills include:

- **Writing in your voice** — a short style guide, fetched whenever the model drafts something for you: British spelling, short sentences, no exclamation marks.
- **Filing an expense claim** — which form, which receipts, and who approves what, written once by the person who knows and used by everyone.
- **Drawing a chart** — the colours, fonts and labelling rules, so every chart it makes matches the rest of your documents.
- **Using the ticketing system at work** — what each field means and what a well-formed query looks like, so the model can drive a tool that did not exist when it was trained.
- **Checking a contract before you sign it** — the clauses a lawyer always looks at, in the order she looks at them.
