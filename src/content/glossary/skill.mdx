A **skill** is a document of instructions that a model can fetch when it decides the job needs them.

A model learns nothing during a conversation, so anything it picks up after training has to arrive as text put in front of it. A skill is that, tidied up: the model is shown a list of skill names with one line each on when they apply, and asks for the full document only when one looks relevant. That request is an ordinary tool call, and the thing that comes back is instructions instead of a search result.

Why it works this way:

- **A person with a folder of checklists does the same** — you do not memorise the pre-flight checklist, you know one exists and fetch it.
- **One line each is cheap** — loading every skill in full, every time, would be enormous and almost all of it irrelevant.
- **Nothing is retrained** — a new procedure can be written in the morning and used that afternoon.

This is also why telling a model something useful in one conversation does nothing for the next one.
