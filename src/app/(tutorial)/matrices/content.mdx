# A Thousand Questions at Once

<Lead>
The graphics card that runs ChatGPT was invented to make videogames look good. The same operation that spins a 3D dragon across your screen is the operation a neural network uses to think. It's called matrix multiplication. By the end of this chapter you'll see why one kind of chip does both jobs.
</Lead>

## A Matrix Is a Grid of Vectors

In the Vectors chapter we described a thing, like an animal, with a list of numbers that measure different properties: big, scary, hairy, cuddly, fast, fat. We call that list a **vector**. Mostly we worked with one vector at a time, a single animal and its six numbers.

It is often useful to write down a whole list of vectors together. We lay them out in a table, and we call that table a **matrix**. In a matrix of animals we put one row for each animal, like cat and dog and bear, and one column for each property. The cat's "scary" number sits in the same column as the bear's, so every column holds the same property read across all the animals.

<MatrixGridWidget>
Each row is one animal's vector, laid out across the property columns, and the whole grid is the matrix. Switch tabs to see the same table for the other kinds of vectors from the Vectors chapter: RPG characters, foods, instruments. Same grid, different things.
</MatrixGridWidget>

<KeyInsight>
**A matrix is a grid of vectors.** Write a list of vectors out as rows and the grid you get is a matrix. Here each row is one animal and each column is one property.
</KeyInsight>

## Multiplying a Vector by a Matrix

In the previous chapter we showed that you can take the **dot product** of two vectors: a single number that says how much the two vectors describe a similar thing, and how big they both are. We write it `vectorA · vectorB`, and [the Vectors chapter](/vectors) has the details.

We can build on that to multiply a vector by a matrix. It means taking the dot product of the vector with every vector in the matrix. The result is a new vector, made of the dot products of the input vector with each vector in the matrix.

<DetectorStackWidget>
Pick an input animal. It shows up as the amber row at the top, above the matrix of reference animals. The result is the row at the bottom, labelled with the input and given a new set of dimensions, one per reference animal: bear-like, dog-like, and so on. Click an output cell, or the matrix row it came from, to highlight the pair and read off the dot product that produced it.
</DetectorStackWidget>

You can think of a matrix as **transforming** an input vector from one set of dimensions to a new set of dimensions. Here it changes an animal from its scores on the property dimensions, big and scary and the rest, into how similar it is to each of the other animals.

<KeyInsight>
**Multiplying a vector by a matrix transforms it into new dimensions.** The input's dot product with each row becomes one number of the output. The vector that went in described by properties comes out described by its similarity to each animal in the matrix.
</KeyInsight>

## A Layer of a Neural Network Is a Matrix

In the Vectors chapter we saw that a single neuron is a dot product: it multiplies the input by a vector of weights and adds them up. A whole layer of neurons is a stack of these dot products, one per neuron, so we can write the layer's weights as a matrix with one row per neuron. Running the layer is then one matrix multiply: the weight matrix times the input vector gives every neuron's weighted sum at once.

A neuron does one more thing after the weighted sum. It passes the result through an **activation function**, which squashes it into a smooth answer between 0 and 1. So a layer is a matrix multiply, then an activation function applied to the whole output vector.

<LayerMatrixWidget>
Each tab is a layer of neurons written as a weight matrix. Multiply it by the input to get every neuron's weighted sum at once, then read the "after sigmoid" column to see the activation function applied. The animal detectors reuse the reference animals as weights; the AND and OR tabs are the logic-gate neurons from earlier chapters.
</LayerMatrixWidget>

<KeyInsight>
**A layer of a neural network is a matrix multiply, then an activation function.** The weight matrix holds one row of weights per neuron, so multiplying by the input runs every neuron's dot product at once. The activation function then shapes each result.
</KeyInsight>

## Attention Is a Matrix Multiply Too

Attention is the same operation once more. In the Attention chapter, a token looks at every other token by taking the dot product of its own **query** vector with each other token's **key** vector. That is one vector, the query, multiplied by a matrix, the keys of all the other tokens stacked as rows. The result is a vector of match scores, one per token, exactly like the output of the detector layer.

Attention then runs those match scores through **softmax** to turn them into attention weights that add up to 1, saying how much to draw from each token. The scoring step itself, though, is just a vector times a matrix.

<AttentionMatmulWidget>
This is the worked example from the Attention chapter. The keys of "cat", "dog", and the filler "blah" are stacked as rows. Multiplying by the query for "it" gives a match score for each: the nouns score high, the filler scores low. Same operation as the detector layer, with keys for rows and a query for the input.
</AttentionMatmulWidget>

## The Same Math Spins 2D and 3D Worlds

Time to close the loop on the cold open. The exact same multiply-and-add that re-describes an animal also re-describes a point's position in space. Feed a point's coordinates through the right matrix and it comes out rotated.

Every frame of a 3D game does this to every vertex of every model: multiply by a matrix to spin the world, tilt the camera, and pose the character. A single frame is millions of these multiply-adds. So chipmakers built graphics cards that do millions of them in parallel, all for the sake of games.

Then neural networks turned out to be mostly matrix multiplication as well. The same chips built to spin dragons were already perfect for running detector stacks by the million. The hardware for games became the hardware for AI. That's the answer to the puzzle from the top of the chapter.

That is the same activation function from the layer section, made visible: a matrix alone keeps straight lines straight, and the activation is what curves them.

## What's Next

A neural network is a stack of these matrices, one per layer, with an activation function after each. Its whole skill lives in the numbers inside those matrices, the learned weights. Training is the search for the right numbers. The next chapters are about how that search works: how gradient descent feels its way downhill to the matrices that solve the problem.
